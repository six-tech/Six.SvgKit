# Usage Patterns

Learn how to effectively combine these classes and methods to create powerful SVG processing workflows.

## Method Chaining

Six.SvgKit is designed for method chaining to create readable optimization pipelines:

```csharp
var result = Svg.FromFile("input.svg")
    .Query()
    .ConvertShapesToPaths()
    .MergePaths()
    .RoundPathSegments(2)
    .RemoveEmptyNodes()
    .CleanupAttributes()
    .CompressOutput()
    .Build()
    .SizeComparisonInPercentage(p => Console.WriteLine($"Reduced by {p:F1}%"));

result.ToFile("output.svg");
```

## Conditional Operations

Apply operations based on conditions:

```csharp
var builder = svg.Query();

if (optimizeForWeb)
{
    builder.DefaultOptimizations();
}

if (targetFormat == "icon")
{
    builder.MonoIconsOptimizations();
}

var result = builder.Build();
```

## Batch Processing

Process multiple files efficiently:

```csharp
var files = Directory.GetFiles("input", "*.svg");

Parallel.ForEach(files, file =>
{
    var result = Svg.FromFile(file)
        .Query()
        .DefaultOptimizations()
        .Build();
    
    var outputPath = Path.Combine("output", Path.GetFileName(file));
    result.ToFile(outputPath);
});
```
