# Overview

This guide covers how to create and manage documentation for your .NET project using **Astro.js Starlight** with the **Six theme**. You'll learn how to create new documentation pages, use Astro components, organize content, and configure the sidebar navigation.

The documentation system is built on:
- **Astro.js**: Modern static site generator
- **Starlight**: Documentation-focused Astro theme
- **Six Theme**: Custom theme from Six Technology

<Aside type="tip">
    **Quick Start**: Documentation files are located in `docs/src/content/docs/` and use either `.md` or `.mdx`
    extensions. The `.mdx` format allows you to use React-like components within your content.

    This solution template uses the [Six theme](https://github.com/six-tech/Six.StarlightTheme),
    which is a custom theme built on top of Starlight. It provides a clean, modern look with additional components and
    styling options.
</Aside>

# Creating New Documentation Pages

## File Structure and Naming

Documentation pages are organized in the `docs/src/content/docs/` directory. For example:

```
docs/src/content/docs/
├── introduction.md                    → /introduction/
├── setup-and-configuration.md         → /setup-and-configuration/
├── nuget/
│   ├── nuget-secrets.mdx              → /nuget/nuget-secrets/
│   ├── nuget-feeds.mdx                → /nuget/nuget-feeds/
│   └── nuget-publish.mdx              → /nuget/nuget-publish/
└── project-documentation/
    ├── setting-up-documentation.mdx   → /project-documentation/setting-up-documentation/
    └── creating-documentation.mdx     → /project-documentation/creating-documentation/
```

## Page Frontmatter

Every documentation page must start with **YAML frontmatter** that defines the page metadata:

```yaml
---
title: Page Title                    # Required: Appears in browser tab and navigation
description: Page description        # Required: Used for SEO and page previews
sidebar:
  label: Custom Sidebar Label       # Optional: Override sidebar display name
  order: 10                        # Optional: Control sidebar ordering
  hidden: false                    # Optional: Hide from sidebar navigation
  attrs:
    class: special-page            # Optional: Add CSS classes
draft: false                       # Optional: Mark as draft (hidden in production)
---
```

<Aside type="tip">
    **Required Fields**: Both `title` and `description` are required for all documentation pages. Missing these will
    cause build errors.
</Aside>



# Configuring Sidebar Navigation

The sidebar navigation is configured in the `astro.config.mjs` file. Here's how to add your new documentation pages:

## Understanding the Sidebar Structure

The sidebar is organized into groups with items:

```javascript
sidebar: [
    {
        label: 'Getting Started',           // Group label
        items: [
            {label: 'Introduction', slug: 'introduction'},
            {label: 'Setup and Configuration', slug: 'setup-and-configuration'},
        ],
    },
    {
        label: 'Testing',                   // Another group
        items: [
            {label: 'Running Tests', slug: 'testing/running-tests'},
        ],
    },
]
```

## Adding New Pages

<Steps>

    1. **Identify the appropriate group** - Decide which existing group your page belongs to, or if you need to create a
    new group.

    2. **Add the page to the group** - Add a new item object to the appropriate group's `items` array:    
    `{label: 'Creating Documentation', slug: 'project-documentation/creating-documentation'}`

    3. **Create new groups if needed** - If your page doesn't fit into existing groups, create a new group with the
    appropriate label and items array.

</Steps>

### Example Configuration

Here's how to add a page to an existing group:

```javascript
{
    label: 'Creating Documentation',
    slug: 'project-documentation/creating-documentation'
}
```

And here's how to create a new group:

```javascript
{
    label: 'New Section',
    items: [
        {label: 'New Page', slug: 'new-section/new-page'},
    ],
}
```

## Advanced Sidebar Configuration

You can also configure individual sidebar items with additional options:

```javascript
{
    label: 'Advanced Guide',
    slug: 'advanced/guide',
    attrs: {
        class: 'advanced-item',         // Add CSS classes
        target: '_blank'                // Open in new tab
    }
}
```

For external links in the sidebar:

```javascript
{
    label: 'External Resource',
    link: 'https://external-site.com',
    attrs: {
        target: '_blank',
        rel: 'noopener'
    }
}
```


# Working with Assets and Images

## Adding Images

Place images in the `docs/src/assets/` directory and reference them using relative paths:

```markdown
![Description](../../assets/image-name.png)
```

For the Six theme, you can use hero images:

```markdown
![Six Hero](../../assets/six-csharp-template-banner-wide-1980-01.png)
```
