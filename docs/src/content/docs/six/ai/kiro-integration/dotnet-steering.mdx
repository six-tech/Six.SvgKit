# Introduction

The .NET Steering Files provide comprehensive guidance for modern .NET development across all platforms and application types, from web APIs to desktop applications, with emphasis on performance, maintainability, and industry best practices.

<Aside type="note">
**Steering File Interdependencies**: Steering files are designed to work together, with many referencing and building upon others. 
    
    For example, .NET steering files automatically incorporate C# coding style guidance, ensuring that all generated code for APIs, Blazor components, and Avalonia applications follows the same performance patterns, memory management, and modern language features. 
    
    This creates a unified development experience where all code maintains consistent quality and style across different technologies.
</Aside>

# General .NET Development

<a id="solution-structure-steering"></a>
## Solution Structure Steering

The Solution Structure Steering provides guidance for organizing .NET solutions with consistent build configuration, SDK management, and project structure. These steering files ensure maintainable, scalable solution architectures across teams and projects.

### What It Does

This steering file enforces proper .NET solution organization by:
- Standardizing solution-wide build properties through `Directory.Build.props`
- Managing SDK versions consistently with `global.json`
- Establishing consistent project structure and naming conventions
- Configuring EditorConfig for code style enforcement across the solution

### File Patterns
- `*.sln` and `*.slnx` solution files
- `Directory.Build.props` and `Directory.Build.targets`
- `global.json` and `nuget.config`
- Project organization in logical folder structures

## C# Coding Style Steering

The C# Coding Style Steering establishes modern C# coding standards leveraging the latest language features, performance patterns, and maintainable code practices for building robust applications.

### What It Does

This steering file enforces:
- Modern C# language features (C# 13) including collection expressions and primary constructors
- Performance-oriented patterns with Span&lt;T&gt;, Memory&lt;T&gt;, and ValueTask
- Memory management best practices with ArrayPool and stackalloc
- Code quality standards with analyzers and nullable reference types

### File Patterns
- All `*.cs` files in .NET projects
- `*.csproj` project configuration files
- `.editorconfig` and analyzer configuration files
