# Introduction

The Web Development Steering Files provide comprehensive guidance for building modern, performant web applications using TypeScript and Astro.js, with emphasis on type safety, performance optimization, and developer experience. These steering files ensure scalable, maintainable web applications with optimal performance and modern development practices.

<Aside type="note">
**Steering File Interdependencies**: Steering files are designed to work together, with many referencing and building upon others. 
    
    For example, .NET steering files automatically incorporate C# coding style guidance, ensuring that all generated code for APIs, Blazor components, and Avalonia applications follows the same performance patterns, memory management, and modern language features. 
    
    This creates a unified development experience where all code maintains consistent quality and style across different technologies.
</Aside>

# TypeScript Coding Style Steering

The TypeScript Coding Style Steering establishes modern TypeScript development standards with emphasis on type safety, performance optimization, and maintainable code patterns for web applications and libraries.

### What It Does

This steering file provides guidance for:
- Modern TypeScript capabilities with strict mode configuration
- Advanced types including utility types, conditional types, and template literal types
- Comprehensive TypeScript compiler options for maximum safety
- Generic patterns with constraints and inference
- Type-safe error handling with Result types
- Memory-efficient patterns and async optimizations
- Tree shaking and bundle optimization strategies
- ESLint configuration with TypeScript-specific checks
- Framework integration with React, Vue 3, and Node.js

### File Patterns
:::note[Documentation-Specific Steering File]
This steering file is specifically designed for documentation projects and only applies to files within the `docs/` directory.
:::

- `docs/**/*.ts` and `docs/**/*.css` TypeScript and styling files in documentation projects
- `docs/**/*.scss` Sass styling files for documentation
- Files matching the pattern `"docs/**/*.js", "docs/**/*.ts", "docs/**/*.md", "docs/**/*.mdx", "docs/**/*.css", "docs/**/*.astro"`

# Astro.js Coding Style Steering

The Astro.js Coding Style Steering provides comprehensive guidance for building fast, modern websites using Astro's island architecture, static generation, and multi-framework support for optimal performance and developer experience.

### What It Does

This steering file establishes:
- Build-time optimization for maximum performance
- Content collections with type-safe content management
- Automatic image processing and format conversion
- Multi-framework support (React, Vue, Svelte, Solid.js)
- Island architecture with selective hydration
- Type-safe component interfaces and flexible slot patterns
- Partial hydration with client-side JavaScript only where needed
- Automatic lazy loading and intelligent prefetching
- SEO optimization with proper meta tags and Schema.org integration
- Markdown and MDX support with content collection patterns

### File Patterns
:::note[Documentation-Specific Steering File]
This steering file is specifically designed for documentation projects and only applies to files within the `docs/` directory.
:::

- `docs/**/*.astro` component files in documentation projects
- `docs/**/*.js`, `docs/**/*.ts`, `docs/**/*.md`, `docs/**/*.mdx` content and configuration files
- `docs/**/*.css` and styling files for documentation
- `docs/astro.config.mjs` configuration files
