# Overview

The **Six.SolutionTemplate** provides comprehensive AI development support through multiple complementary systems designed to enhance your development workflow with intelligent automation, consistent code generation, and context-aware assistance. 

These AI tools work together to provide a complete development experience that scales from individual developers to large teams.

<Aside type="tip">
    Since **Six.SolutionTemplate** standardizes project structure, dependencies, in-repository documentation, 
    development patterns, the AGENTS.md file, Cursor Rules and Kiro Rules/Hooks can be largely pre-written and **Six.
    SolutionTemplate** leverages this strategy to provide a consistent, high-quality AI development experience.
    
    **Basically, only AGENTS.md requires minor customization for each new project.**
</Aside>

# AGENTS.md

The **AGENTS.md** provides a standardized, open-format approach to AI development support that works across multiple AI coding agents and tools. This system ensures that AI assistants have comprehensive, project-specific context and instructions.

## What It Provides

The AGENTS.md file in **Six.SolutionTemplate** includes:
- **Project Overview**: Clear description of the template's purpose and capabilities
- **Setup Commands**: Both automated and manual setup instructions
- **Testing Instructions**: Comprehensive testing workflows and coverage requirements
- **NuGet Packaging**: Complete package creation and publishing guidance
- **Documentation**: Astro.js Starlight documentation system setup
- **Code Standards**: C# coding conventions and best practices
- **CI/CD Integration**: GitHub Actions workflows and automation

## Benefits of Standardization

- **90% Ready-to-Use**: The template's AGENTS.md is essentially complete and only requires minor customization
- **Consistent Experience**: Same guidance across different AI tools and team members
- **Comprehensive Context**: AI agents understand your entire project structure and requirements
- **Automated Workflows**: Clear instructions for testing, packaging, and deployment

# Cursor Integration

The **Cursor Integration** provides an advanced rule-based system that ensures consistent, high-quality code 
generation through detailed development patterns and best practices. 

This system is specifically designed for the **Cursor IDE** and provides granular control over AI-assisted development.

<Aside type="note">
    **Rule Interdependencies**: Many rules reference and build upon other rules to ensure consistent code generation.

    For example, ASP.NET Core rules automatically incorporate C# coding style guidelines, so all generated API code follows the same performance patterns, memory management, and modern language features.

    This creates a cohesive development experience where all code maintains consistent quality and style across different technologies.
</Aside>


## Available Rule Categories

### .NET Development Rules
- **General .NET**: Solution structure, testing, benchmarking, library development, dependency management
- **C# Coding Style**: Modern language features, performance patterns, memory management
- **ASP.NET Core**: API development, Fast Endpoints, Orleans distributed systems
- **Blazor**: Component architecture, state management, performance optimization
- **Avalonia**: MVVM patterns, custom controls, XAML styling
- **CI/CD**: Build systems, NuGet publishing, code signing

### Web Development Rules
- **TypeScript**: Type safety, performance optimization, modern JavaScript features
- **Astro.js**: Island architecture, static generation, multi-framework support

### Specialized Rules
- **Documentation**: README generation, AI-friendly documentation
- **Specification-Driven Development**: Requirements, design, and implementation workflows

# Kiro Integration

The **Kiro Integration** provides steering files and hooks for automated workflow triggers and AI agent actions. This system enables proactive automation that responds to file changes, user actions, and other development events.

<Aside type="note">
    **Steering File Interdependencies**: Steering files are designed to work together, with many referencing and building upon others.

    For example, .NET steering files automatically incorporate C# coding style guidance, ensuring that all generated code for APIs, Blazor components, and Avalonia applications follows the same performance patterns, memory management, and modern language features.

    This creates a unified development experience where all code maintains consistent quality and style across different technologies.
</Aside>


## Steering Files

- **.NET Steering Files**: Comprehensive guidance for all .NET development scenarios
- **Web Development Steering**: TypeScript and Astro.js development patterns
- **Documentation Steering**: Professional documentation generation

## Hooks System
- **C# Documentation Scanner**: Automatically scans project documentation for relevant context
- **Documentation Updater**: Keeps documentation synchronized with code changes
