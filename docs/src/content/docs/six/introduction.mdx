# Welcome to Six Solution Template

**Six Solution Template** is a production-ready solution template that provides a complete foundation for 
building .NET libraries and applications. It eliminates the need to manually configure common development tools, 
CI/CD pipelines, and project standards, allowing you to focus on writing code instead of setting up infrastructure.

<Aside type="tip">
    **Ready to get started?** Run `dotnet run setup.cs` from the solution root for guided setup or follow our [Setup 
    and Configuration](./../setup-and-configuration/) guide.
</Aside>

# What's Inside?

<CardGrid>

<LinkCard title="🚀 Breeze Setup" description="Get started in minutes with automated setup scripts" href="./../setup-and-configuration/">
### One-Command Setup
- **Automated Configuration**: `dotnet run setup.cs` handles everything
- **Guided Setup Process**: Interactive prompts for your project details
- **Prerequisites Check**: Ensures all required tools are installed
- **Project Metadata**: Automatically configures repository info, authors, and licensing
</LinkCard>

<LinkCard title="📁 Standardized Structure" description="Organized directory structure for maximum productivity" 
          href="./../structure/str-directories/">
### Directory Organization
- **libs/**: Library projects with NuGet packaging support
- **apps/**: Application projects (console, web, desktop)
- **tests/**: Test projects with strict naming conventions
- **benchmarks/**: Performance benchmarking with BenchmarkDotNet
- **docs/**: In-repository documentation site
</LinkCard>

<LinkCard title="⚙️ Configuration Management" description="Hierarchical configuration system with sensible defaults" href="./../structure/str-configuration/">
### Smart Configuration
- **Directory.Build.props Hierarchy**: Cascading configuration from root to projects
- **global.json**: SDK version management and rollForward policies
- **nuget.config**: Multi-environment NuGet feed management
- **StyleCop & .editorconfig**: Consistent code style and formatting
</LinkCard>

<LinkCard title="🔧 C# Development Scripts" description="All automation in C# using .NET file-based apps" href="./../scripts/">
### Unified Scripting
- **No Shell Scripts**: Everything in C# using .NET 10 file-based apps
- **Cross-Platform**: Works identically on Windows, macOS, and Linux
- **Interactive Runner**: Menu-driven interface for all development tasks
- **Integrated Tooling**: Full IntelliSense and debugging support
</LinkCard>

<LinkCard title="📦 NuGet Feed Standardization" description="Professional package management across environments" href="./../nuget-feeds/">
### Package Management
- **Multi-Environment Feeds**: Local, development, staging, production
- **Secure Credentials**: Environment variable-based authentication
- **Automated Publishing**: Scripts handle versioning and publishing
- **Symbol Packages**: Debug support with .snupkg files
</LinkCard>

<LinkCard title="📚 Professional Documentation" description="In-repository docs with custom Starlight theme" href="./../project-documentation/">
### Documentation Site
- **Astro.js Starlight**: Modern, fast documentation framework
- **Custom Six Theme**: Professional, branded appearance
- **Automated Deployment**: GitHub Pages integration
- **Search & Navigation**: Built-in full-text search and responsive design
</LinkCard>

<LinkCard title="🚀 CI/CD Workflows" description="GitHub Actions workflows out of the box" href="./../github-workflow-integration/">
### Automated Pipelines
- **PR Validation**: Automated testing and quality checks on pull requests
- **Release Automation**: Streamlined deployment to production
- **Quality Gates**: Code analysis, testing, and security scanning
- **Cross-Platform Builds**: Windows, Ubuntu, and macOS support
</LinkCard>

<LinkCard title="🤖 AI Integration" description="Comprehensive AI tooling support built-in" href="./../ai/introduction/">
