# Overview

The **setup script** (`setup.cs`) provides an automated, interactive setup process for configuring your **Six 
Solution Template project**. 

It handles prerequisite validation, dependency installation, and project configuration 
through an intuitive command-line interface.

# Usage

```bash
# From the root of the repository run the following command:
dotnet run setup.cs
```

Upon execution, the script will perform the following tasks:

1. **Prerequisites Check**: Validates required tools (dotnet CLI, npm/pnpm, Node.js)
2. **Package Restoration**: Restores .NET packages from the solution file
3. **Documentation Setup**: Installs documentation dependencies
4. **Interactive Configuration**: Prompts for project metadata
5. **File Updates**: Updates configuration files with your settings
6. **(Optionally) Remove Unneeded Files**: Based on your settings, it will remove unneeded files and directories from 
the repository

# Interactive Configuration

The script will prompt you for the following information:

## NuGet Package Configuration

- **GitHub Repository URL**: Your repository URL (e.g., `https://github.com/owner/repo`)
- **Authors**: Comma-separated list of package authors
- **Copyright**: Copyright text for packages
- **Package Description**: Description for NuGet packages
- **Package Project URL**: Project homepage URL

## Documentation Configuration

- **GitHub Pages URL**: Base URL for documentation (e.g., `https://owner.github.io/repo`)
- **Documentation Title**: Title for the documentation site


# What Will Be Updated?

## Directory.Build.props

Updates the following properties in `libs/Directory.Build.props`:
- `RepositoryUrl`
- `Authors`
- `Copyright`
- `Description`
- `PackageProjectUrl`

## astro.config.mjs

Updates the following properties in `docs/astro.config.mjs`:
- `site` URL for GitHub Pages
- `title` for the documentation site
- `description` from NuGet configuration
- `editLink.baseUrl` for GitHub editing
- Social links and repository references
