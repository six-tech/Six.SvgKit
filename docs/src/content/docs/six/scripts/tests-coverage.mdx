# Overview

The **Coverage Collection** script (`tests-coverage.cs`) provides comprehensive code coverage analysis for all test projects in the Six.SolutionTemplate solution. 
It runs tests with a coverage collection, analyzes the results, and provides detailed metrics and recommendations.

# Purpose

The coverage collection script automates coverage analysis by:
- **Test Execution**: Runs all test projects with the coverage collection enabled
- **Data Collection**: Gathers coverage data using XPlat Code Coverage
- **Analysis**: Parses and analyzes coverage metrics
- **Reporting**: Displays detailed coverage statistics and recommendations
- **Data Management**: Organizes coverage data in timestamped directories

# Usage

```bash
dotnet run scripts/tests-coverage.cs
```

## What It Does

1. **Cleanup**: Removes previous test results and coverage data
2. **Test Discovery**: Finds all test projects in the solution
3. **Coverage Collection**: Runs tests with XPlat Code Coverage
4. **Data Organization**: Creates timestamped directories for coverage data
5. **Analysis**: Parses coverage data and calculates metrics
6. **Reporting**: Displays comprehensive coverage summary

# Coverage Collection Process

## Test Execution

The script runs tests with the following parameters:
- `--collect:"XPlat Code Coverage"`: Enables coverage collection
- `--results-directory`: Specifies where to store coverage data
- `--verbosity minimal`: Reduces output verbosity for cleaner logs

## Data Organization

Coverage data is organized in timestamped directories:
- **Format**: `yyyy-MM-dd_HH-mm-ss-{guid}`
- **Location**: `{test-project}/TestResults/{timestamp-guid}/`
- **Files**: `coverage.cobertura.xml` and related files

## Coverage Metrics

The script analyzes the following metrics:
- **Line Coverage**: Percentage of code lines executed
- **Branch Coverage**: Percentage of code branches executed
- **Total Lines**: Total number of executable lines
- **Covered Lines**: Number of lines executed by tests
- **Total Branches**: Total number of code branches
- **Covered Branches**: Number of branches executed by tests


# Configuration

## Coverage Collection Settings

The script uses XPlat Code Coverage with default settings:
- **Format**: Cobertura XML format
- **Inclusion**: All source code in the solution
- **Exclusion**: Test projects and build artifacts
- **Symbols**: Includes symbol information for debugging

## Coverage Thresholds

You can modify coverage thresholds in the script:

```csharp
var lineThreshold = 0.8;  // 80% line coverage
var branchThreshold = 0.8; // 80% branch coverage
```

## Coverage Recommendations

Customize recommendations based on your project needs:

```csharp
if (overallLineRate < lineThreshold)
{
    // Add custom line coverage recommendations
}
```
