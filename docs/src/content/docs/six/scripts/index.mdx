# Introduction

The **Six Solution Template** includes a collection of **.NET 10's single file apps** that automate common 
development workflows.

<Aside type="tip">
    All scripts are designed to work seamlessly across Windows, macOS, and Linux platforms, providing a consistent development experience regardless of your operating system.
    
    **Note**: All scripts are also used in ci-cd pipelines provided by **Six Solution Template** for automated 
    testing, packaging, and publishing. 
</Aside>

<Aside type="note">
    ### Prerequisites
    
    - **.NET 10 SDK**: Required for running C# file-based apps
    - **Git**: For version control and GitVersion integration
    - **Node.js/pnpm/bun/yarn/npm**: For documentation dependencies (we are using pnpm)
    - **Docker**: For containerized testing (if using integration tests)
    
    **Tip**: See more about file-based apps in the [official documentation](https://learn.microsoft.com/en-us/dotnet/csharp/fundamentals/tutorials/file-based-programs).)
</Aside>

# Troubleshooting

## Common Issues

- **Permission Errors**: Ensure scripts have execute permissions on Unix systems
- **Package Resolution**: Run `dotnet restore` if package resolution fails
- **Path Issues**: Use relative paths and proper working directory handling
- **Environment Variables**: Verify all required environment variables are set
