# Introduction

The **Six Solution Template** includes **pre-configured GitHub Actions workflows** that automate essential
development processes, ensuring consistent quality and streamlined deployment across all projects.

<Aside type="note">
    All workflows are designed to work seamlessly with the template's structure and scripts, providing
    automated testing, documentation deployment, and quality assurance without manual configuration.
    
    ### Prerequisites

    - **GitHub Repository**: Workflows run automatically in GitHub Actions
    - **Template Scripts**: Workflows use the provided [scripts (C# file-based apps) that are used for CLI 
    operations](./../scripts)
    - **Repository Secrets**: Configure NuGet API keys and other credentials as needed as [described here](./../nuget-feeds/nuget-secrets)

</Aside>
