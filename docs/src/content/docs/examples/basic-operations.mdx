# Introduction

Learn the fundamental operations for working with SVG files using Six.SvgKit.

# Loading and Saving SVGs

<Tabs>
  <TabItem label="From File">
    ```csharp
    using Six.SvgKit;
    
    // Load SVG from file
    var svg = Svg.FromFile("input/icon.svg");
    
    // Save to new location
    svg.ToSvgFile("output/icon.svg");
    
    // Get as string
    string svgContent = svg.ToSvg();
    
    // Get as bytes
    byte[] svgBytes = svg.ToBytes();
    ```

  <TabItem label="From String">

# Basic SVG Manipulation

Change elements and attributes in SVG files:

```csharp
using Six.SvgKit;

var svg = Svg.FromFile("input.svg");

// Change fill color of all path elements
var result = svg.Query()
    .Select(node => node.Name == "path")
    .Transform(node => node.SetAttribute("fill", "red"))
    .Build();

// Save the modified SVG
result.ToFile("red-paths.svg");

// Check what changed
result.SizeComparisonInBytes((before, after) => 
    Console.WriteLine($"Size changed from {before} to {after} bytes"));
```

# Working with SVG Properties

Control output formatting and behavior:

```csharp
var svg = Svg.FromFile("input.svg");

// Enable compression (removes whitespace)
svg.CompressOutput = true;

// Disable XML declaration
svg.OmmitXmlDeclaration = true;

string compressedSvg = svg.ToSvg();
svg.ToSvgFile("compressed.svg");
```

# Error Handling

Handle common scenarios gracefully:

```csharp
public static bool TryProcessSvg(string filePath, string outputPath)
{
    try
    {
        var svg = Svg.FromFile(filePath);
        svg.ToSvgFile(outputPath);
        return true;
    }
    catch (FileNotFoundException)
    {
        Console.WriteLine($"SVG file not found: {filePath}");
        return false;
    }
    catch (Exception ex)
    {
        Console.WriteLine($"Error processing SVG: {ex.Message}");
        return false;
    }
}
```
