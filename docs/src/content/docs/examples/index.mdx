# Quick Start

If you're new to Six.SvgKit, start with these basic examples:

## Load and Optimize an SVG

```csharp
using Six.SvgKit;
using Six.SvgKit.Optimizer;

// Load SVG and apply basic optimizations
var result = Svg.FromFile("input.svg")
    .Query()
    .DefaultOptimizations()
    .Build();

// Save optimized version
result.ToFile("optimized.svg");

// Check the results
result.SizeComparisonInPercentage(percentage =>
    Console.WriteLine($"File size reduced by {percentage:F1}%"));
```

## Create an Icon from SVG

```csharp
// Optimize for icon use
var iconResult = Svg.FromFile("logo.svg")
    .Query()
    .MonoIconsOptimizations(width: 32, height: 32)
    .Build();

// Save as SVG and convert to PNG
iconResult.ToFile("icon.svg");
iconResult.ModifiedSvg.ToBitmapFile(MagickFormat.Png24, "icon.png", 32, 32);
```

## Process Multiple Files

```csharp
var svgFiles = Directory.GetFiles("input", "*.svg");

Parallel.ForEach(svgFiles, file =>
{
    var result = Svg.FromFile(file)
        .Query()
        .DefaultOptimizations()
        .Build();
    
    var outputPath = Path.Combine("output", Path.GetFileName(file));
    result.ToFile(outputPath);
});
```
