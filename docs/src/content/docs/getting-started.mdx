# Quick Start

Let's start with a simple example that demonstrates the basic workflow of Six.SvgKit:

## 1. Import Namespaces

```csharp
using Six.SvgKit;
using Six.SvgKit.Optimizer; // If using optimization features
```

## 2. Load an SVG

You can load SVG content from a file or string:

```csharp
// From file
var svg = Svg.FromFile("path/to/your/icon.svg");

// From string
var svgString = @"<svg xmlns=""http://www.w3.org/2000/svg"" width=""24"" height=""24"">
    <circle cx=""12"" cy=""12"" r=""10"" fill=""blue"" />
</svg>";
var svg = Svg.FromString(svgString);
```

## 3. Basic Operations

```csharp
// Get the SVG as a string
string svgOutput = svg.ToSvg();

// Save to file
svg.ToSvgFile("output.svg");

// Convert to byte array
byte[] svgBytes = svg.ToBytes();
```

## 4. Apply Optimizations

```csharp
// Apply basic optimizations
var optimizedSvg = svg
    .Query()
    .DefaultOptimizations() // Requires Six.SvgKit.Optimizer
    .Build();

// Get the optimized SVG
string optimizedOutput = optimizedSvg.ModifiedSvg.ToSvg();
```

# Core Concepts

Understanding these key concepts will help you work effectively with Six.SvgKit:

<CardGrid>
  <Card title="Svg Class" icon="document">

# Configuration Options

Six.SvgKit provides several configuration options to customize its behavior:

## Output Compression

Control how SVG output is formatted:

```csharp
var svg = Svg.FromFile("input.svg");

// Enable compression (removes whitespace)
svg.CompressOutput = true;

// Disable XML declaration
svg.OmmitXmlDeclaration = true;

string compressedSvg = svg.ToSvg();
```

## Metadata Tracking

Add metadata to track SVG instances during batch processing:

```csharp
var metadata = new SvgMetadata { /* your metadata */ };
var svg = Svg.FromFile("input.svg")
    .WithMetadata(metadata);
```

# Troubleshooting

## Common Issues

**Package Not Found**
- Ensure you're using the correct package source
- Check that your project targets .NET 9.0 or later

**SVG Parsing Errors**
- Verify your SVG content is well-formed XML
- Check for unsupported SVG features or elements

**Performance Issues**
- Use parallel processing for batch operations
- Consider using optimization presets for common scenarios
