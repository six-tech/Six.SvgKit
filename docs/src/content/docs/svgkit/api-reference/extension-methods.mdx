# Introduction

The optimizer package provides numerous extension methods for the `SvgQueryBuilder` class.

# Preset Optimizations

## DefaultOptimizations

Applies a comprehensive set of standard optimizations.

```csharp
var result = svg.Query()
    .DefaultOptimizations()
    .Build();
```

| Operations Performed |
|---------------------|
| Remove XML declaration |
| Remove empty nodes, attributes, and text |
| Remove empty containers |
| Collapse unnecessary groups |
| Clean up attributes |
| Compress output |

| Returns | Description |
|---------|-------------|
| `SvgQueryBuilder` | The current builder instance for method chaining |

---

## MonoIconsOptimizations

Optimizes monochromatic icon sets with specific parameters.

```csharp
var result = svg.Query()
    .MonoIconsOptimizations(width: 32, height: 32, decimalPlaces: 1)
    .Build();
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `width` | `int` | `24` | Target width for the SVG |
| `height` | `int` | `24` | Target height for the SVG |
| `decimalPlaces` | `int` | `2` | Decimal precision for path coordinates |

| Operations Performed |
|---------------------|
| Convert shapes to paths |
| Merge paths with similar styles |
| Round path segments to specified precision |
| Apply default optimizations |
| Set standard icon attributes |

| Returns | Description |
|---------|-------------|
| `SvgQueryBuilder` | The current builder instance for method chaining |

|----------------------|

# Usage Examples

## Preset Optimization

```csharp
// Quick optimization for most SVGs
var result = svg.Query()
    .DefaultOptimizations()
    .Build();

// Specialized optimization for icons
var iconResult = svg.Query()
    .MonoIconsOptimizations(width: 24, height: 24, decimalPlaces: 1)
    .Build();
```

## Custom Optimization Pipeline

```csharp
var result = svg.Query()
    .ConvertShapesToPaths(2)           // Convert shapes for consistency
    .MergePaths()                      // Combine similar paths
    .MergePathCommands()               // Optimize path data
    .RoundPathSegments(1)              // Aggressive rounding for web
    .RemoveEmptyNodes()                // Clean up empty elements
    .RemoveEmptyAttributes()           // Remove empty attributes
    .CollapseGroups()                  // Remove unnecessary groups
    .CleanupAttributes()               // Normalize attributes
    .RemoveXmlDeclaration()            // Remove XML declaration
    .CompressOutput()                  // Minify output
    .Build();
```

## Selective Cleanup

```csharp
// Focus on cleanup without path modifications
var cleanResult = svg.Query()
    .RemoveEmptyNodes()
    .RemoveEmptyAttributes()
    .RemoveEmptyText()
    .RemoveEmptyContainers()
    .CollapseGroups()
    .CleanupAttributes()
    .Build();

// Focus on path optimization
var pathResult = svg.Query()
    .ConvertShapesToPaths()
    .MergePaths()
    .MergePathCommands()
    .RoundPathSegments(2)
    .Build();
```
