# Six.SvgKit

**Six.SvgKit** is a comprehensive .NET library designed for parsing, manipulating, and optimizing SVG (Scalable Vector Graphics) files. Built with performance and accessibility in mind, it provides developers with powerful tools to work with SVG content programmatically.

## What is Six.SvgKit?

Six.SvgKit is a modern .NET library that simplifies SVG processing tasks. Whether you need to optimize SVG files for web performance, batch process icon sets, or manipulate SVG content programmatically, Six.SvgKit provides an intuitive API with powerful optimization capabilities.

## Why Choose Six.SvgKit?

### Performance First
- **Parallel Processing**: Batch operations run in parallel for maximum performance
- **Memory Efficient**: Optimized for processing large numbers of SVG files

## Common Use Cases

Six.SvgKit is perfect for:

- **Icon Set Optimization**: Batch optimize icon collections for web applications
- **SVG Cleanup**: Remove unnecessary elements and attributes from SVG files
- **Format Conversion**: Convert SVG files to bitmap formats for different platforms

## Library Architecture

Six.SvgKit consists of two main packages:

### Six.SvgKit (Core Library)
The core library provides fundamental SVG parsing, manipulation, and serialization capabilities:
- SVG document parsing and AST representation
- Element and attribute manipulation
- Query builder for complex operations
- File I/O and format conversion

### Six.SvgKit.Optimizer (Optimization Extensions)
The optimizer package extends the core library with advanced optimization techniques:
- Path optimization and merging
- Shape-to-path conversion
- Attribute cleanup and compression
- Predefined optimization presets
