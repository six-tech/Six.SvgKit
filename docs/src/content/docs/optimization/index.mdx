# Overview

Six.SvgKit.Optimizer provides powerful tools for reducing SVG file sizes while maintaining visual quality. This guide covers optimization strategies, techniques, and best practices for different use cases.

# Understanding SVG Optimization

SVG optimization involves removing unnecessary elements, simplifying paths, and normalizing attributes while preserving the visual appearance and functionality of the graphic. The goal is to achieve the smallest possible file size without compromising quality.

# Optimization Presets

Six.SvgKit provides ready-made optimization presets for common scenarios.

## Default Optimizations

The `DefaultOptimizations()` method applies a comprehensive set of safe optimizations suitable for most SVGs:

```csharp
using Six.SvgKit;
using Six.SvgKit.Optimizer;

var result = Svg.FromFile("input.svg")
    .Query()
    .DefaultOptimizations()
    .Build();

// Save optimized SVG
result.ToFile("optimized.svg");

// Check the size reduction
result.SizeComparisonInPercentage(percentage =>
    Console.WriteLine($"Size reduced by {percentage:F1}%"));
```

**What DefaultOptimizations includes:**
- Remove XML declaration
- Remove empty nodes and attributes
- Remove empty text and containers
- Collapse unnecessary groups
- Clean up attribute values
- Compress output

## Monochromatic Icons Optimization

For icon sets and simple graphics, use `MonoIconsOptimizations()`:

```csharp
var result = Svg.FromFile("icon.svg")
    .Query()
    .MonoIconsOptimizations(width: 24, height: 24, decimalPlaces: 2)
    .Build();
```

**Parameters:**
- `width`: Target width (default: 24)
- `height`: Target height (default: 24)  
- `decimalPlaces`: Coordinate precision (default: 2)

**Additional optimizations for icons:**
- Convert shapes to paths
- Merge similar paths
- Round path coordinates
- Remove viewBox attribute
- Set standard fill attributes

# Quick Start Examples

## Basic Optimization

```csharp
// Quick optimization for most SVGs
var result = Svg.FromFile("input.svg")
    .Query()
    .DefaultOptimizations()
    .Build();

result.SizeComparisonInPercentage(p => Console.WriteLine($"Reduced by {p:F1}%"));
result.ToFile("optimized.svg");
```

## Icon Optimization

```csharp
// Specialized optimization for icons
var result = Svg.FromFile("icon.svg")
    .Query()
    .MonoIconsOptimizations(width: 32, height: 32, decimalPlaces: 1)
    .Build();

result.ToFile("optimized-icon.svg");
```

## Custom Pipeline

```csharp
// Custom optimization pipeline
var result = Svg.FromFile("complex.svg")
    .Query()
    .ConvertShapesToPaths()
    .MergePaths()
    .CleanupAttributes()
    .RemoveEmptyNodes()
    .CompressOutput()
    .Build();
```
