**Six SvgKit** is a modern .NET library designed for **parsing, manipulating, and optimizing SVG (Scalable
Vector Graphics) files**.

## 🚀 Features

- **🔍 SVG Parsing & Manipulation**: Parse SVG files from strings or files with a fluent API
- **⚡ Advanced Optimization**: Reduce file sizes by up to 70% while maintaining visual quality
- **📦 Batch Processing**: Process multiple SVG files in parallel with configurable presets
- **🖼️ Format Conversion**: Convert SVG to PNG, WebP, JPEG, and other bitmap formats
- **🏃‍♂️ High Performance**: Optimized for processing large numbers of SVG files efficiently
- **🛡️ Production Ready**: Comprehensive testing, robust error handling, and detailed documentation


## Installation

Install **Six.SvgKit** via NuGet Package Manager:

```bash
# Core library
dotnet add package Six.SvgKit

# With optimization extensions (recommended)
dotnet add package Six.SvgKit.Optimizer
```
